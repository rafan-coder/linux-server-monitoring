# Linux Server Monitoring Dashboard

A beginner-friendly Linux server monitoring project built using Ubuntu, Prometheus, Node Exporter, and Grafana.

## Project Overview

This project monitors a Linux server and visualizes important system metrics in a Grafana dashboard.

## Technologies Used

- Ubuntu Linux
- Prometheus
- Node Exporter
- Grafana
- PromQL
- WSL

## Monitoring Metrics

The dashboard monitors:

- CPU Usage
- RAM Usage
- Disk Usage
- Network Receive Traffic
- Network Transmit Traffic
- Server Uptime

## Architecture

Ubuntu Linux
↓
Node Exporter
↓
Prometheus
↓
Grafana
↓
Monitoring Dashboard
